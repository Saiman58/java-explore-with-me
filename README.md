# 🎫 Explore With Me - java

**Explore With Me**

Это бэкенд-приложение для афиши мероприятий. Пользователи могут создавать события, искать их по разным параметрам, оставлять заявки на участие, подтверждать их, оставлять комментарии и многое другое.

Проект демонстрирует навыки построения REST API, микросервисной архитектуры, работы с базами данных, контейнеризации Docker и следования принципам ООП и SOLID.

## 🏗 Архитектура (микросервисы)

Проект разделен на два независимых сервиса:

| Сервис        | Порт | Назначение |
|---------------|------|------------|
| **ewm-stats** | `9090` | Сервис статистики: сбор и выдача информации о запросах |
| **ewm-main**  | `8080` | Основной сервис: вся бизнес-логика приложения |

### Статистика разделена на подмодули:
- **stats-server** — HTTP-сервис для сбора статистики
- **stats-client** — HTTP-клиент для отправки статистики из основного сервиса

## 📌 Функциональность основного сервиса

### 👤 Пользователи (Users)
- Создание, обновление, удаление пользователей
- Получение списка пользователей с пагинацией

### 🎪 Категории (Categories)
- Создание, обновление, удаление категорий (только для администратора)
- Получение списка категорий с пагинацией

### 📅 События (Events)
- **Публичные эндпоинты:**
    - Поиск событий по фильтрам (текст, категории, платные/бесплатные, даты, сортировка)
    - Получение подробной информации о событии
- **Приватные эндпоинты (для пользователей):**
    - Создание, обновление событий
    - Получение своих событий
    - Получение заявок на участие в своих событиях
    - Изменение статуса заявок
- **Административные эндпоинты:**
    - Поиск событий с фильтрацией
    - Модерация событий (публикация/отклонение)

### 📝 Заявки на участие (Requests)
- Подача заявки на участие в событии
- Подтверждение/отклонение заявки владельцем события
- Получение списка своих заявок
- Отмена своей заявки
- Просмотр заявок на конкретное событие

### 📚 Подборки (Compilations)
- Создание, обновление, удаление подборок (админ)
- Получение списка подборок с фильтрацией по закреплению
- Получение подборки по ID

### Дополнительная функциональность
**Комментарии к событиям (Comments)**
- Добавление комментариев к событиям
- Редактирование и удаление своих комментариев
- Получение списка комментариев к событию с пагинацией

## 🔗 API Эндпоинты

###  Категории (Публичные)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `GET` | `/categories` | Получить все категории (с пагинацией) |
| `GET` | `/categories/{catId}` | Получить категорию по ID |

###  Категории (Админ)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/admin/categories` | Создать новую категорию |
| `PATCH` | `/admin/categories/{catId}` | Обновить категорию |
| `DELETE` | `/admin/categories/{catId}` | Удалить категорию |
| `GET` | `/admin/categories` | Получить все категории (с пагинацией) |

###  Подборки (Публичные)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `GET` | `/compilations` | Получить все подборки (с фильтром по pinned) |
| `GET` | `/compilations/{compId}` | Получить подборку по ID |

###  Подборки (Админ)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/admin/compilations` | Создать новую подборку |
| `PATCH` | `/admin/compilations/{compId}` | Обновить подборку |
| `DELETE` | `/admin/compilations/{compId}` | Удалить подборку |
| `GET` | `/admin/compilations` | Получить все подборки (админ) |

###  События (Публичные)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `GET` | `/events` | Поиск событий с фильтрацией |
| `GET` | `/events/{id}` | Получить событие по ID |

###  События (Приватные - для пользователей)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `GET` | `/users/{userId}/events` | Получить события пользователя |
| `POST` | `/users/{userId}/events` | Создать новое событие |
| `GET` | `/users/{userId}/events/{eventId}` | Получить событие пользователя по ID |
| `PATCH` | `/users/{userId}/events/{eventId}` | Обновить событие пользователя |
| `GET` | `/users/{userId}/events/{eventId}/requests` | Получить заявки на событие пользователя |
| `PATCH` | `/users/{userId}/events/{eventId}/requests` | Изменить статус заявок на событие |

###  События (Админ)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `GET` | `/admin/events` | Поиск событий (админ) |
| `PATCH` | `/admin/events/{eventId}` | Редактировать событие (публикация/отклонение) |

###  Пользователи (Админ)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/admin/users` | Создать нового пользователя |
| `DELETE` | `/admin/users/{userId}` | Удалить пользователя |
| `GET` | `/admin/users` | Получить всех пользователей |

###  Заявки на участие (Приватные)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `GET` | `/users/{userId}/requests` | Получить свои заявки |
| `POST` | `/users/{userId}/requests?eventId={eventId}` | Создать заявку на участие |
| `PATCH` | `/users/{userId}/requests/{requestId}/cancel` | Отменить свою заявку |
| `GET` | `/users/{userId}/requests/events/{eventId}` | Получить заявки на событие |

###  Комментарии

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/events/{eventId}/comments?userId={userId}` | Создать комментарий |
| `PATCH` | `/events/{eventId}/comments/{commentId}?userId={userId}` | Обновить комментарий |
| `GET` | `/events/{eventId}/comments` | Получить комментарии к событию |
| `DELETE` | `/events/{eventId}/comments/{commentId}?userId={userId}` | Удалить комментарий |

## 💾 Работа с базами данных

### Основной сервис (PostgreSQL)
- **Пользователи** — хранение данных пользователей
- **Категории** — справочник категорий событий
- **События** — информация о мероприятиях
- **Заявки** — запросы на участие
- **Подборки** — коллекции событий
- **Комментарии** — отзывы и обсуждения

### Сервис статистики (PostgreSQL)
- **Хиты** — записи о каждом обращении к эндпоинтам
